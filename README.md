# Projecte ECO · Sales d'escolta

Pàgines web amb els sons de cada missió dels quaderns de llenguatge musical **Projecte ECO** (3r ESO).
Els quaderns porten un codi QR que porta aquí.

- `index.html` · portada amb les tres temporades
- `t1/` · Temporada 1 · Els primers ecos
- `t2/`, `t3/` · aviat

Tots els sons es generen al navegador (Web Audio): no hi ha gravacions ni dependències.
